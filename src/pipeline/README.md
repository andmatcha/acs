# `pipeline` モジュール

## 責務

- 受信した入力フレームをどのように加工し、どこへ流すかを表現・実行する中核モジュールです。

## 主な処理

- `config.rs` でパイプライン定義の型を持ちます。
- `engine.rs` で共有の `IngressFrame` を処理し、最終的な送信計画 `DispatchPlan` を生成します。
- `message.rs` でパイプライン内部を流れる `RouteMessage` を定義します。
- `modules` でフィルタ、変換、分類、ルータの実装を組み立てます。

## 実装の要点

- 各パイプラインは `filter -> transform* -> classify -> route` の順で処理されます。
- フレーム型は `session` ではなく共有モジュールから受け取り、処理コアの依存方向を単純に保っています。
- 1 つの入力フレームから複数メッセージへ分岐したり、複数出力へ配送したりできる柔軟な構成です。
- `route` コマンドだけでなく、`control` も内部ではこのパイプラインエンジンを使って DS4 入力を送信形式へ変換しています。
