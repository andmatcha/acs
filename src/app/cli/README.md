# `app/cli` モジュール

## 責務

- `acs` のコマンドラインインターフェース全体を担当します。
- 引数解析、設定ファイル読み込み、既定値解決、実行モードごとの組み立てを行います。

## 主な処理

- `mod.rs` で `control` / `monitor` / `route` / `send` / `xbee-test` / `controllers` / `ports` / `version` を振り分けます。
- `config.rs` で JSON ファイルまたはディレクトリを読み、設定をマージします。
- `control.rs` で DS4 入力を `compact` 化し、出力フォーマットへエンコードして送信します。
- `monitor.rs` で 1 個以上のシリアル入力を監視します。
- `route.rs` で入力・出力・パイプライン・テンプレートを解決して中継処理を起動します。
- `send.rs` でダミーペイロードを一定周期で送信します。
- `xbee_test.rs` で `base` / `rover` 間の PacketACv6 / PacketJFv1 往復試験を行います。
- `paths.rs` と `signal.rs` で設定/ログの保存先解決と Ctrl-C 停止を共通化しています。

## 実装の要点

- 引数解析は外部 CLI クレートに依存せず、各コマンドが手書きで行っています。
- 設定ファイルも手書き JSON パーサで読み、必要な JSON 機能だけに絞っています。
- 設定は CLI 引数とファイル設定を後勝ちで統合し、ポートやログディレクトリを最終解決してから `session` と `pipeline` を起動します。
- `route` は組み込みテンプレートと設定ファイル定義テンプレートの両方を扱えます。
