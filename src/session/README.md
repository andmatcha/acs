# `session` モジュール

## 責務

- 各コマンドの実行セッションを管理し、シリアル I/O、ダッシュボード表示、ログ保存を一体で動かします。

## 主な処理

- `runtime.rs` で入力監視、出力書き込み、イベントループ、定期レンダリングを管理します。
- `dashboard.rs` で表示用ダッシュボードとログ出力をまとめます。
- `logger.rs` でログファイル作成と入出力記録を行います。
- `event.rs` でセッション内の入力イベント型を定義します。

## 実装の要点

- シリアル reader thread から届くイベントは `mpsc` チャネルで集約し、メインループ側で処理します。
- 入出力が同じポートの場合は monitor と writer を共有し、ポートを二重オープンしないようにしています。
- 入力フレーム本体は `ingress` モジュールの共有型を使い、`pipeline` などの処理コアが `session` に依存しないようにしています。
- monitor 表示は `line` / `packet` / `wrap` / `crlf` を切り替えられ、改行単位、受信チャンク単位、端末幅で折り返す raw stream、または ASCII/UTF-8 内の CR/LF を実改行にした表示として記録します。
- ダッシュボードは Space キーで一時停止でき、停止時には残っている未表示行も flush してから終了します。
- `acs control` では PC キーボードの `R` / `r` を `packetacv6` の `USB_READ` 要求として扱います。
