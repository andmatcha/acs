# `output/formats/packetjfv1` モジュール

## 責務

- `PacketJFv1` 形式のダミーフレーム生成を担当します。

## 主な処理

- `JF` ヘッダ、シーケンス、フラグ、エンコーダ値、CRC を持つ 16 バイトフレームを組み立てます。
- `send` コマンドが動作確認や監視用途で使う固定ペイロードを返します。

## 実装の要点

- 実装は状態を持たないシンプルなビルダです。
- compact report を入力に取る `OutputDriver` は未実装で、現在はダミーデータ生成専用です。
- CRC は共通ユーティリティの `crc16_ccitt_false` を利用しています。
