# `output` モジュール

## 責務

- シリアルへ送る出力形式を抽象化し、コマンド側が形式名だけで扱えるようにします。

## 主な処理

- `OutputFormat` 列挙型で利用可能な出力形式を管理します。
- 形式名の文字列から内部表現を解決します。
- compact report をエンコードできる形式では `OutputDriver` を生成します。
- `io` コマンド向けに、各形式のダミーペイロード生成も提供します。
- `io` / `route` で使う mixed format stream decoder を提供し、既知 packet の境界検出と CRC 検証を共通化します。

## 実装の要点

- 形式ごとの情報は `OUTPUT_FORMATS` テーブルに集約されています。
- 「compact report からエンコード可能かどうか」と「ダミーフレームだけ作れるかどうか」を分けて扱っています。
- 実際のフォーマット実装は `output/formats` 以下へ分離されています。
