# `ui` モジュール

## 責務

- ターミナル上で使う軽量なテキストダッシュボードを提供します。

## 主な処理

- ポートごとの入力・出力履歴を最大 10 件ずつ表示します。
- `hex` / `ascii` / `utf8` / 複合表示の切り替えに対応します。
- 転送レートと理論帯域使用率を見出しに表示します。
- Space キー入力を拾って一時停止/再開アクションを返します。

## 実装の要点

- 代替スクリーンとカーソル制御用 ANSI エスケープを直接使い、外部 TUI ライブラリに依存していません。
- 毎回全画面を描き直さず、前回表示との差分だけを出力するため比較的軽量です。
- Unix では termios を直接操作して canonical mode と echo を外し、非ブロッキング気味にキー入力を読んでいます。
