# `input` モジュール

## 責務

- 入力デバイスから生データを取得し、内部で扱いやすい表現へ整形します。
- 現状は DUALSHOCK 4 入力と、その入力を 8 バイトの compact 形式へ変換する処理を持ちます。

## 主な処理

- `ds4_hid.rs` で HID デバイスの列挙、選択、オープン、レポート読み取りを行います。
- `compact.rs` で USB/Bluetooth の DS4 レポートを正規化し、ボタン/スティック情報を compact report に詰め直します。

## 実装の要点

- `hidapi` を薄く包み、デバイス一覧と選択エラーを分かりやすい型で表現しています。
- DS4 の入力レポートは USB 64 バイトと Bluetooth 10 バイト以上の両方を受け入れ、先頭 10 バイトを基準に共通化しています。
- compact report では D-pad の方向を独自ビット表現に変換し、後段の出力エンコーダが扱いやすい 8 バイトへ圧縮しています。
